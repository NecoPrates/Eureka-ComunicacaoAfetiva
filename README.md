# Comunicação Afetiva

Projeto inicial para desenvolver um programa de comunicação empática e assertiva.

## Estrutura

- `index.html` — interface principal do aplicativo
- `styles.css` — estilos visuais
- `script.js` — lógica de geração de mensagem

## Como testar

1. Abra `index.html` em um navegador.
2. Preencha os campos:
   - `Contexto`
   - `O que você precisa transmitir`
   - `Tom`
   - `Para quem`
3. Clique em `Gerar mensagem`.
4. Use o texto gerado como base para uma comunicação afetiva.
